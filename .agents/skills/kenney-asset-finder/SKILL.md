# Kenney Asset Finder

Use the Kenney All-in-1 preview catalog as the starting point: <https://kenney.nl/data/itch/preview/>. The project is a Phaser 4 math adventure whose root `index.html` opens the game directly.

When asked to find assets:

1. Search the catalog's filter and category controls by theme, visual style, and asset type. Inspect the preview image for shortlisted packs.
2. Open each selected pack's official Kenney asset page to confirm its category, tags, formats or dimensions when listed, and license. Do not infer a license from another pack.
3. Recommend only packs that fit the requested use. Explain the fit in Traditional Chinese and preserve each pack's English name. Include a direct preview or official asset-page link.
4. If the catalog exposes only a name or preview, label the description as an inference from that preview instead of presenting it as official copy.
5. If the user asks for a comparison, use a concise table with English name, Traditional Chinese name, contents/use, category or style, license (when verified), and source link.
6. Do not download, copy, or integrate assets into the project unless the user asks for that change. When integration is requested, use the chosen pack only, keep assets organized under `public/assets/`, and retain any license or attribution files that accompany it.
