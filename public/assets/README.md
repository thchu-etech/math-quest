# 遊戲素材

Vite 會將這個資料夾直接複製到 `dist/assets/`。遊戲中的資產 URL 以 `/assets/...` 為根，部署到 GitHub Pages 時請使用相對的 asset base 或由程式產生完整路徑。

- `images/characters/`：角色與動畫影格。
- `images/backgrounds/`：背景與場景插畫。
- `images/tilesets/`：地形、平台與 tilemap 圖集。
- `images/ui/`：介面圖示與按鈕。
- `audio/music/`、`audio/sfx/`、`audio/voice/`：音樂、音效與語音。
- `fonts/`、`data/`：字型與遊戲資料。
- `kenney/`：依素材包分資料夾保存的原始素材。
