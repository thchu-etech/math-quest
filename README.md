# 星際數學隊

使用 Phaser 4 製作的國小數學闖關遊戲。玩家操作太空探險家移動與跳躍，蒐集正確答案完成五個星球任務。

## 開始遊戲

在專案資料夾執行 npm install，再執行 npm run dev，並用瀏覽器開啟 Vite 顯示的本機網址。

請透過本機伺服器或部署後的網站遊玩，不要直接用 file:// 開啟 index.html。

## 操作與規則

- 左右方向鍵或 A、D：移動
- 空白鍵、上方向鍵或 W：跳躍
- 手機和平板可用畫面下方的觸控按鈕
- 答對加 10 分，答錯扣 5 分
- 共五關，每關三題：加法、減法、乘法、除法與綜合挑戰

遊戲素材取自 public/assets/kenney/new-platformer-pack/，原始授權檔保留在素材包資料夾中。
