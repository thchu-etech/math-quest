# 數學星球｜闖關大冒險

使用 Phaser 3.90.0 製作的繁體中文數學闖關遊戲。共五關，每關蒐集一個正確答案即可前進；答對加 10 分，答錯扣 5 分。題目涵蓋加法、減法、乘法、除法與混合運算。Phaser 引擎已放在專案的 `vendor/` 資料夾，不需連外載入。

## 開始遊戲

在專案資料夾啟動本機網頁伺服器：

```sh
ruby -run -e httpd . -p 8000 -b 127.0.0.1
```

然後在瀏覽器開啟 `http://localhost:8000`。伺服器視窗保持開啟時即可遊玩；按 Ctrl+C 停止伺服器。遊戲本身不需要網路連線。

## GitHub Pages

專案已附 GitHub Actions 部署工作流程。將檔案推送到 GitHub 儲存庫的 `main` 分支後，在該儲存庫的 **Settings → Pages** 將來源設為 **GitHub Actions**；之後每次更新 `main` 都會重新部署。

## 操作方式

- 鍵盤：←／→ 或 A／D 移動，空白鍵／↑／W 跳躍。
- 手機與平板：使用遊戲畫面下方的方向鍵與跳躍按鈕。
